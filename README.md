# 🎲 Baccarat Betting Management System

A desktop application built in **Java** and **JavaFX** for managing Baccarat betting strategies, tracking performance, and analysing results.

The application was developed as a freelance project and provides an intuitive interface for managing betting plans, bankrolls, recovery systems, and long-term compounding strategies.

---

## 📌 Overview

This application allows users to manage multiple Baccarat betting systems while automatically tracking profits, losses, statistics, and bankroll progression.

Unlike a simple betting calculator, the application includes persistent save functionality, recovery management, performance analytics, and configurable betting plans.

---

## ✨ Features

### Betting Systems

- Multiple configurable betting plans
  - 500-1
  - 1000-1
  - Double Up
  - Combined Player & Banker tracking
- Separate Player and Banker systems
- Automatic bet progression
- Undo functionality
- System locking after stop limits are reached

---

### Bankroll Management

- Track current bankroll
- Track total profit and loss
- Configurable base stake
- Stop-loss limits
- Stop-profit limits
- Automatic bankroll updates

---

### Recovery Pit

A built-in recovery management system allowing users to recover losses using configurable risk levels.

Features include:

- High, Medium and Low risk profiles
- Visual recovery grid
- Progress tracking
- Dynamic recovery targets
- Automatic completion detection

---

### Compounding Planner

The application includes a compounding planner for long-term bankroll growth.

Features:

- Daily profit targets
- Goal tracking
- Current balance monitoring
- Daily compounding calculations
- Progress table
- Automatic daily progression

---

### Statistics Dashboard

Track betting performance with live statistics including:

- Win/Loss percentages
- Stage win rates
- First and second bet success rates
- Maximum winning streak
- Maximum losing streak
- Pie chart visualisations
- Player vs Banker performance

---

### Save & Load

Application state is automatically persisted between sessions.

Saved information includes:

- Betting systems
- Bankroll
- Current progress
- Compounding plans
- User settings
- Statistics
